# Automations · Mission Control

A single-file, static status dashboard for a personal fleet of Claude-built automations — daily/weekly scheduled jobs (a DJI O3 marketplace watcher, FPV and AI news digests, a geotagged AI news feed) plus longer-running projects (an Electron/Three.js globe visualization app and a one-off research doc). Styled to match the dark "mission control" design system used across this account's other repos (FPV, Extern): CSS-variable theming, Chakra Petch/JetBrains Mono typography, HUD-bracket header, and card-based layout with color-coded status badges (Active / In Development / Complete). It's plain HTML/CSS/JS with no build step and no external dependencies beyond Google Fonts, so it drops straight into GitHub Pages. Status is hand-maintained, not live-polled — the "Last updated" timestamp reflects when the board was last refreshed by hand.
